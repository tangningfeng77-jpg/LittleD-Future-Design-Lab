# 小D大屏工程维护规则

本工程用于用户已成功运行的 Android 13 BOE 大屏。修改、同步电脑版或生成新 APK 前，先读本目录的 `大屏APK打包规范.md` 与 `release-profile.json`。

- 桌面 `/Users/tang/Desktop/LittleD-Complete/` 是用户继续编辑的主项目；安卓工作默认不得修改、删除或覆盖它。
- 后续用户明确提出的新要求优先；其余设备兼容设置继承成功基线 2026.11.04.4。
- 不将电脑 public 直接全量覆盖安卓 assets 后发布。使用 `release-baseline/` 的桌面/安卓差异进行合并，保留新版业务内容及安卓适配。
- 保留原生 AudioRecord 与 LittleDAudio 桥、点击开始/结束持续交流、停止后释放麦克风，以及录音失败时恢复播放的逻辑。
- 保留视口约束、76/24 布局、参考镜头及禁用触摸缩放；保留 1920 渲染上限和 1440/1280 自动降档、关闭 AO、256 反射/200ms。不能默认为 4K 实时渲染。
- 保持 applicationId 和现有签名证书不变；每次发布 versionCode 必须高于所有已发布版本。不得重新生成签名或建议卸载来回避升级冲突。
- API 密钥不得嵌入 APK、网页资源、日志或文档；沿用一次导入、设备加密存储。
- 运行与变更相符的构建、Lint、测试和签名验证。报告区分模拟器、用户实机反馈和未测试事项。
- 新交付使用新目录，不覆盖原成功交付；用户确认后新增基线记录，保留原始成功基线。
