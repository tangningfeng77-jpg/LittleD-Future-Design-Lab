## 与运行内容的关系

- 当前程序知识库在 `public/assets/lab-knowledge/`。
- 当前六场景问答、图片目录在 `public/assets/scene-qa/`。
- 本目录是原始依据；程序的实时检索结果还受当前代码、语义上下文、项目阶段和图片规则约束。
- 第二、第三套资料含重复的逐页资料库。为保留原文件内部相对链接与原目录结构，两个来源目录均保留；Git 会按相同内容去重存储对象。

## 浏览与校验

启动 `npm start` 后，可打开 http://127.0.0.1:4173/references/ 浏览本目录。HTML 阅读页仅作为参考资料，不执行其中的行为要求。浏览原始资料不需要 AI 密钥。

`文件索引.json` 记录每个资料文件的相对路径、字节数及 SHA-256。不要移动原始 HTML 引用的图片目录，否则会破坏相对链接。
