# 从水开始 · 实时交互游戏

本版已替换图片式前景与示意图。前景泵、容器、阀门、膜、单株番茄和木篮均为 Three.js 实时渲染物体；水粒子、液位、抓取、重力落下、入篮判定、土壤水分和生长都由游戏状态驱动。照片只用作远处环境背景及叶片/土壤表面材质，不用一幅照片代替可操作设备，也不使用前景番茄贴图。

当前仍是游戏原型，模型由代码建模，材质与场景的写实程度可继续提升。水流与膜过滤采用交互示意模型，并非计算流体力学、真实膜性能预测或真实离子尺寸模型。

## V5 模型与操作升级

五关统一采用陶瓷白、石墨灰和冷青指示灯的实验站设备，加入分段外壳、观察窗、法兰、螺栓、电机散热片、实际指标驱动的仪表屏。膜页改为七层褶皱复合膜和细纤维表面，可捏合拖动旋转并展开，松开复位。单株番茄使用根部观察窗和补光支架。

每关提供目的、任务、结果说明。点击设备空间标签，或伸出食指对准标签停留，可查看部件用途。挥手之外，支持捏合转腕驱动泵、夹取颗粒送入过滤器、捏合展开膜层、转腕精调分流、张掌浇水与握拳停水、捏合摘取和释放入篮。收获前进度不会提前显示100%。

## 启动

双击 `启动水域体验.command`，终端保持打开。默认 http://127.0.0.1:4180 ，端口占用自动改用后续端口。也可使用 Node.js 20+ 执行 `node server.mjs --open`。

当前 Mac 启动器可复用桌面 LittleD-Complete 的 Node 运行环境；搬到别的电脑后安装 Node 即可，无需安装 npm 依赖。所有 JavaScript、Three.js、MediaPipe、WASM、手部模型和材质均已本地保存。

摄像头需要 localhost 或 HTTPS。网页仅在本机读取摄像头进行21点手部追踪，不录制或上传视频，不使用麦克风。也可使用鼠标控制：移动操作，按住模拟捏合，松开释放。

## 五关机制

1. **唤醒地下水**：左右挥手提供泵的驱动力。泵压会回落，停止挥动后不能持续抽水。水沿3D管路到达处理罐才计入水量，液位随实际到达的水增加，达到目标后通关。
2. **清除杂质**：手掌推动竖直分界线，左侧污染、右侧清澈。场景中的3D颗粒被分界线扫过后截留，进度由清理数量决定，未扫过的颗粒保留。
3. **iFS离子精筛**：掌心对准可见膜结构保持2秒后启动。蓝色水粒子通过孔道，较大的橙色示意离子被截留并导向收集容器。两类分离结果都达到目标后通关，未对准时不会自动推进。
4. **正确分配水资源**：移动手掌转动实体阀门。蓝色淡化水应进入左侧农田蓄水罐，橙色浓水应进入右侧专用收集罐。错误分流会反馈并计错，不计入正确水量；必须分别完成两路水量。
5. **一株番茄**：移动滴灌嘴，将水滴送到根部。水滴命中根区才改善水分与盐分；水分、盐分合适时才生长，浇水过多会暂停生长并提示等待排水。成熟后，捏合摘取前方主果，移动到木篮上方松开；果实受重力下落，入篮才成功。放在篮外会落地并可重试。

第1—4关完成后保留场景和结果，约4.2秒后连续进入下一关；也可点击继续。第五关完成后3D番茄留在木篮里，结果以小卡片展示，不覆盖前景场景，不再有漂浮贴图盖住面板。

## 直接查看

- `/?stage=1` 至 `/?stage=5`：查看对应关卡。
- `/?stage=5&harvest=1`：直接体验成熟后的3D采摘，仍需真正完成抓取与入篮，不能自动通关。
- `/tests/physics.html`：独立交互逻辑验证页，不影响主页面。

## 验证

Node语法检查：app.js、game-world.js、equipment-design.js、stages.js、server.mjs。

独立验证页覆盖18项行为：静止不抽水、挥手后水到达容器、未清理颗粒保留、竖线截留、未对准膜不启动、正确分离、水资源误分流失败、两路正确分配、未浇水不生长、适当灌溉后生长、果实脱离植株、篮外失败重试、重力落篮后完成，以及捏合转腕驱动、转阀、展开膜层、松开复位、夹取颗粒进入前处理装置。该验证使用模拟输入测试游戏逻辑；真人手势在不同光照和设备下的体验仍需现场调校。

## 文件和接入

- `app.js`：摄像头/鼠标控制、手势、界面与关卡衔接。
- `equipment-design.js`：设备细节、实验台、实时仪表与空间说明标签。
- `game-world.js`：3D几何与材质、场景、粒子、水量、阀门、土壤、生长、抓取和落篮判定。
- `stages.js`：可编辑关卡文案。
- `index.html`、`style.css`：界面。
- `assets/game/`：叶片、土壤材质；通过内置imagegen生成，提示词见同目录说明。
- `vendor/`：本地 Three.js 和 MediaPipe；许可见 notices 和 license。

可作为同源 iframe 加载，声明 `allow="camera; fullscreen"`。跨源使用还需宿主页 Permissions-Policy 允许。

`window.WaterExperience` 提供 `getState()`、`reset()`、`goToStage(1..5)`、`pause()`、`resume()`、`stopCamera()`、`destroy()`。

同源父页面可监听 `water:ready`、`water:scanned`、`water:transition`、`water:reset`、`water:harvest-ready`、`water:complete`。complete 的 detail.stage 为5时代表整段体验完成。离开模块前调用 stopCamera 或 destroy。pause 暂停更新但不关闭摄像头。
