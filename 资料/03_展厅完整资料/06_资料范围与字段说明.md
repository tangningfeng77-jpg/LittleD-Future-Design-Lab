# 实验室资料库｜范围与字段说明

资料版本：2026年10月27日。四份PPT按实际幻灯片顺序建立316条页面记录；原生内容、原图、图内文字和人工内容说明分别保存。

## 内容层级

| 层级 | 内容 | 主入口 |
|---|---|---|
| 机构与团队 | 组织归属、核心管理团队、研究与工程成员、学术委员会、历史专家、人才统计版本 | 主题正文1.0.1—1.0.4 |
| 合作与成果 | 联合机构、企业与品牌、平台认定、教学成果、个人奖项、学生指导成果、人才计划 | 主题正文1.0.5—1.0.7 |
| 科研与资源 | 论文、著作、教材、知识产权、课程、社会服务、设备、样机和联系信息 | 主题正文1.0.8—1.0.11 |
| 共性技术 | 数据、概念与关系、模型、生成、感知、工作流、岗位助手 | 主题正文第一、三、四部分 |
| 行业场景 | 农业、公安政务、时尚、物流、数字商业、教育与互动空间 | 主题正文第二、五部分 |
| 图文档案 | 316页、502张去重原图、327个阅读分区、原生表格、图表和视频目录 | 逐页逐图资料库、02全文 |
| 公开知识 | 54条知识、96项公开来源及页面／原图／分区关联 | 05来源目录、08知识条目、09关联表 |

## 记录字段

| 对象 | 字段 |
|---|---|
| 人员 | 姓名、实验室职务、职称、研究方向、公开成果、来源、版本日期 |
| 合作 | 名称、品牌或法定主体、关系类型、时间、对应项目、源页 |
| 荣誉与成果 | 名称、年份、层级、所属主体、共同完成或指导关系、证书或公开来源 |
| 项目 | 项目名称、行业、联系人、业务问题、数据、知识、模型、软件设备、实施阶段、量化记录 |
| 页面 | 文件编号、实际页码、检索标题、场景分类、正文章节、原生内容、图片引用、公开知识关联 |
| 原图 | 图片编号、内部图名、字节哈希、像素、出现位置、裁切、内容说明、OCR、分区、知识编号 |
| 分区 | 标签、内容说明、归一化坐标、裁图、文字识别、关联知识 |
| 公开知识 | 条目编号、标题、原理或公开事实、直接来源、检索日期、关联原图 |

## 来源与状态

项目状态按可研、调研与蓝图、规划、研发、设计稿、测试、试点、交付、验收、运营记录；图像属性按实物照片、结构图、软件界面、生成效果、模拟数据、概念示意记录。

人员职称和人才数量保留其公开时间和统计版本。黄琦“副教授／教授”、谭诗弋“工程师／高级工程师”在不同材料中的差异分别入库。17条官网成员记录属于网站栏目数；PPT研究序列和工程经验分组属于材料统计快照。

农业建设期、装备投资、浓水路线和现金流累计值存在不同源页口径，原值与复算值分别保存。数字门店的展台、行为记录、时间长度和交易数据分别归档。项目方法、技术论文与行业标准分别记录其来源。

## 未载字段

源材料未载完整记录的字段包括：实验室准确成立日期、完整学术委员会名册、统一日期队伍总数、部分客户法定主体、实验室独立成果总数、部分奖项逐件证书、少年宫专属课程与交付、实验室独立商务联系信息。

## 文件覆盖

全部502张原图保留源文件字节及SHA256。316页均有主题位置和公开知识关联；502张原图、327个分区均有知识编号。原生文字、OCR与备注为来源转录，原文件中的标题和用语原样保留。11个视频保留文件目录，逐帧内容不在本库文字分析范围内；飞书正文未提供的图片占位与不可外显表格不含原样图像记录。
